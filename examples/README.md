# Example Pest Test Files

This directory contains example Pest test files to demonstrate the CodeLens functionality.

## Files

- `ExampleTest.php` - Basic test examples
- `UserTest.php` - Real-world user authentication tests

## Try It Out

1. Open any of these PHP test files
2. You'll see CodeLens icons appear:
   - At the top: "Run File"
   - Above each test: "Run" button
   - Above describe blocks: "Run Group" button
3. Click any icon to execute the test(s)
